### 4. P6 修复：开场第一句对白不显示

- 根因：`DialogueBoxUI` 在 Update 里惰性订阅 `LineChanged`，而
  `GameManager.Start→EnterOpening→Play` 在 Start 阶段就派发首行——
  所有 Start 先于所有 Update，首行无订阅者，对话框约 3 秒不显示。
- 修法：订阅挪到 `Start()`（`Subscribe()` 幂等），并在契约 `IDialogueService`
  新增 `ReplayCurrent()`（重派当前行，不改进度/不重置计时），订阅成功后立刻补一次。
- **play 实测**：重进播放后 t=1.86、idx=0 时对话框已激活且显示首句
  「唔……早上了，肚子好饿。」（修复前此处为空框）。

### 6. 布局重排：E 键不再多重触发

交互只看水平 X 距离，X 挤在一起会一次 E 同时触发两件东西
（比如同时进接水特写和收拾特写）。装配菜单现在**无条件写死**各交互物 X，按 ≥2.0 间距排开：

| 物体 | X | 交互半径 |
|---|---|---|
| 早餐 | −4.2 | 1.0 |
| 收拾桌面 | −2.2 | 1.0 |
| 画板 | 0.0 | 1.2 |
| 水源 | 2.2 | 1.0 |
| 收拾书架 / 画笔 | 4.2 | 1.0 |

相邻区间刚好相切不重叠（`<` 比较）。**美术想微调外观请动 Y/Z 或子物体，别改这些 X。**
另：猫的落脚点也改为无条件写死（它的游走以出生点为锚点，播放残留会让它卡在角落）。

## 新坑

1. **`RoomInteractable.Update` 是 `protected virtual`**：子类直接写 `void Update()`
   会**隐藏**基类方法 → E 键惰性订阅永不执行 → 「走近了按 E 没反应」。
   必须 `protected override void Update() { base.Update(); ... }`。
2. **改完 Editor 脚本必须先 refresh 再跑菜单**：否则跑的是旧编译产物，
   新增的无条件赋值不生效（本次猫位置就栽在这）。
3. **特写里藏主角**：主角是根物体，不在 RoomWorld 下，`SetRoomVisible` 管不到它。
4. **画笔这类「进度触发显形」的物体要挂 RoomWorld 下**：挂 GameSystems 会穿帮进特写；
   且显形发生在特写打开期间也没关系——父级恢复激活后自然显示。
