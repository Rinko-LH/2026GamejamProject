### 3.2 回归中发现并修复的真 bug

1. **浮点定值 tick 欠涨**：`0.05f×1200` 累加和 59.999 < 60，达标线永远差一丝
   （真实帧率 dt 同样可能欠涨）→ `DrawingCanvas.Tick` 加 `CompletionEpsilon=0.01f`

2. **场景序列化值不随代码默认值更新**：改 `paintingSeconds=60` 后场景里仍是 15
   （装配日志「15 秒达标」暴露）→ 案值一律在装配菜单 1.5 节显式写死。
   教训：**公开字段改默认值 ≠ 改场景**，K2 风险登记。
3. **污染播放态**：前置会话遗留的播放态下跑装配菜单，导致部分场景对象 Awake 不跑
   （InputManager.Instance=null、PlayerStats.Water=null、GM.OnGUI 每帧 NRE），
   且存盘会把运行时对象写进场景 → 铁律 R8：跑菜单前必须 `manage_editor stop`，
   异常态识别特征=「物体在但 Instance/字段为 null」。

## 环境备忘（MCP 桥接，2026-10-17 实测）

- play 模式下域重载后，execute_code 可能读到旧域快照（表现为 Time.time=0.0），
  真实会话状态以 Editor.log（`[流程] 自由探索开始` 等日志）或重复读取为准。
- 桥接会间歇性 "No Unity Editor instances found"，重试即可。
- 本机 AssetImportWorker 是编辑器子进程，不算多实例；真正的多开才需警惕。
- Roslyn 编译器不可用，execute_code 需用 `compiler="codedom"`（C# 6）：
  一条语句只能声明一个变量、不支持本地函数、System.Tuple 与内置程序集冲突。
