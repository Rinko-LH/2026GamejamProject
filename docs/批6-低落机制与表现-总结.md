## 交付内容

### S7 低落·机制侧（`DrawingCanvas.Tick` 内化）

- `public float lowMoodScale = 1.5f`（装配写死）。Tick 内：
  `ElapsedSeconds += dt / (IsLowMood ? lowMoodScale : 1f)`——
  达标线仍是 60s（进度条语义不变），低落时每秒真实时间只推进 1/1.5，
  60s 达标变 90s 真实时间。
- 倍率**只在 Tick 内化**：DBI 调用点传原始 dt，`Flow.PaintingSeconds` 统计
  口径不受倍率污染（契约⑤明文）。`Tick(float dt)` 签名与调用点不动。
- 实测：非低落 Tick(1)=+1.000；satiety 15（低落）Tick(1)=+0.667；恢复 +1.000。

### S8 低落·表现侧（新文件 `Assets/Scripts/Mood/MoodFeedback.cs`）

- **① 全屏去饱和**：UIRoot 下 `MoodOverlay` 宿主（居中零尺寸），Start 自建
  全屏灰 Image（0.42,0.42,0.48），raycastTarget=false 不挡交互；
  LowMoodChanged → alpha 0↔0.55 匀速淡入淡出（1s）。装配里用 SetSiblingIndex
  挪到 SettlementPanel 之前——盖 HUD 不盖结算面板。
- **② 低落气泡**：玩家子物体 `MoodBubble`（装配注入 bubbleAnchor，禁查找），
  淡黄便签色块 + TextMesh「好累……」，sortingOrder 15110 压所有场景精灵；
  自动跟随玩家，特写隐藏玩家时一起隐藏；Build 前先清同名残留防双份。
- **③ 移速 -20%**：`Simple2DMovement.FixedUpdate` 经
  `Services.Stats.IsLowMood` 自查 ×0.8（规范约定移速项由移动脚本自查）。
- `IResettable`：alpha 归零、气泡收起（ResetRun 实测通过）。
- 字体用 `Font.CreateDynamicFontFromOSFont("Microsoft YaHei")`（2022.3 无 Arial）。

### 结算态时钟让位（批 5 遗留小瑕疵）

- `ClockDisplay.Update`：`Services.Flow.State == Settlement` 时隐藏 Label、
  跳过刷新；离开结算自动恢复。实测：结算隐藏 ✓ → R 重开恢复 ✓。

### 装配（第 19 节）

`MoodFeedback` 挂 GameSystems；`MoodOverlay` 挂 UIRoot；
`overlayHost`/`bubbleAnchor`(=player)/`fadeSeconds`/`maxAlpha` 装配注入；
画板节补写 `lowMoodScale=1.5`（K2）。
