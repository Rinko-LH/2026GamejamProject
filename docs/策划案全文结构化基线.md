## 一、游戏概述

| 项目 | 内容 |
|---|---|
| 游戏名称 | 《今天要画画》（暂定名，待定） |
| 游戏类型 | 2D 叙事生活模拟 / 房间探索（等轴视角，四方向行走） |
| 主题 | ADHD：主线与支线之间反复横跳的焦虑，最终与自我和解 |
| 核心体验 | 一天画完 3 幅画；饥饿/口渴/精神低落不断把玩家拉去支线，猫和偶然发现不断转移注意力 |
| 目标平台 | PC（键鼠操作） |
| 单局时长 | 8～12 分钟（一天对应 8 分钟游戏时间，待调优） |
| 情绪曲线 | 醒来（平静）→ 状态告急（焦虑）→ 收拾/发现（小满足）→ 被打断（烦躁）→ 时间流逝（自责）→ 一天结束（和解） |

## 二、核心玩法循环

1. 醒来：卧床醒来，开场独白点明 ADHD 身份，告知主线"今天要画完 3 幅画"。
2. 状态值弹出：水分 50% / 饥饿 20% / 精神 50%，玩家直观看到"三项都在漏"。
3. 循环体：状态下降 → 主角台词提醒（渴了/饿了/烦了）→ 做支线（吃、收拾、接水）→ 状态恢复但消耗时间 → 回主线画画（衰减减半）→ 再被支线/突发事件拉走。
4. 出口：3 幅画全部完成，或一天时间结束。
5. 结算：客观数据结算（完成画数、专注时长占比、支线次数、被猫捣乱次数）。

四结局流向：主线占比高画完 3 幅 → 专注结局；反复分神最终画完 → 常规结局；时间耗尽未画完 → 分神结局；状态值全部掉光 → 低落结局。

## 四、数值配置表

### 4.1 状态值

| 状态值 | 初始值 | 衰减速度 | 恢复方式 | 恢复量 |
|---|---|---|---|---|
| 水分 | 50% | 0.5%/秒 | 客厅饮水机接水 | +20% |
| 饥饿 | 20% | 0.4%/秒 | 客厅早餐 / 小零食 | +50% / +10% |
| 精神 | 50% | 0.6%/秒 | 收拾桌面 / 整理书架 | +20% |

### 4.2 速率乘区（原稿"隐藏设定"的量化）

| 行为 | 状态衰减倍率 | 说明 |
|---|---|---|
| 画画（主线） | ×0.5 | 专注时掉得慢，奖励专注 |
| 做支线 | ×1.5 | 分神成本更高，制造焦虑 |
| 纯探索 / 走路 | ×1.0 | 基准 |

### 4.3 时间与主线

| 项目 | 数值 | 说明 |
|---|---|---|
| 一天总时长 | 480 秒（8 分钟） | 待调优 |
| 单幅画基础耗时 | 60 秒 | 3 幅共 180 秒，约占一天 37.5%，留出支线空间 |
| 着墨量 / 下笔指标 | 单幅累计下笔 20 秒，或着墨覆盖率达标 | 防止挂机；未达标则时间持续消耗 |

### 4.4 低落机制（替代"游戏失败"）

- 任一状态值低于 20% 进入低落：画画所需时间 ×1.5、移动速度 -20%、画面轻微去饱和；
- 状态恢复后效果解除；
- 一天结束时三项全部低于 10%，触发低落结局。

## 六、结局与结算规则

### 6.1 结局判定

| 结局 | 触发条件 | 文案方向 |
|---|---|---|
| 专注结局 | 一天内完成 3 幅画，且画画时长占总时长 ≥ 60% | "今天几乎没怎么走神" |
| 常规结局 | 一天内完成 3 幅画，但画画占比 < 60% | "画完了，虽然中间岔了好几次" |
| 分神结局 | 一天时间结束，画作未全部完成 | 展示未完成的画，旁白温和不指责 |
| 低落结局 | 一天结束时三项状态全部 < 10%（或中途全部掉光） | "整个人被掏空"，落脚仍是自我接纳 |

### 6.2 结算界面（客观数据）

完成画作数 x/3 ｜ 画画时长/总时长（专注占比）｜ 支线完成次数（吃/收拾/整理/接水分项）｜ 被猫弄乱次数 ｜ 偶然发现次数 ｜ 结局名称 + 一句收尾文案。
