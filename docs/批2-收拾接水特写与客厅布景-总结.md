## 一、已完成部分

### 1. 公共特写基类 CloseupBase（新增）

- **文件**：`Assets/Scripts/CloseupBase.cs`
- **要点**：把三套特写（画板 / 收拾 / 接水）的公共骨架抽出来，收住两处易踩陷阱：
  - **输入只在"进入后"才订阅**——否则触发"进入"的那次 E 会被特写自己再处理一遍，两段式被吞掉一半。
  - **全局总闸门 `RoomInteractable.CloseupActive`**——进特写后玩家坐标没动，房间里 TidySpot / 画笔 / 道具本来还会响应同一个 E，会导致双重结算。
- 另含：客厅隐藏/恢复、相机保存-聚焦-还原、Esc 退出、`IResettable` 复位。

### 2. 收拾特写（重构 + 杂物迁移）

- **文件**：`Assets/Scripts/Quest/TidyCloseup.cs`（重构到基类）、`Assets/Scripts/Quest/TidySpot.cs`
- **要点**：
  - `TidySpot.Interact` 第一段改为**进入收拾特写**；`ExecuteTidy()` / `CancelArm()` 拆成公开方法供特写调用。
  - **客厅里 TidyDesk/TidyShelf 只留家具本体**，3 个杂物与高亮移到特写内（用户要求的"移过去"），做到"走进特写才看见乱，收拾完就没了"。

### 3. 接水特写（S4，新增）

- **文件**：`Assets/Scripts/Quest/WaterCloseup.cs`、`Assets/Scripts/Quest/WaterSource.cs`
- **要点**：走到水源按 E 进特写；**按住鼠标接水**（与画板共用 `PaintHeld`）；水满自动完成：
  `+20 水分` → 扣 `15 游戏分钟`（=7.5 真实秒）→ 上报 `QuestId.Water` → 播台词。
  水位用 `localScale.y` 表现、底边对齐；`IResettable` 水位归零。

### 4. 客厅布景完善（新增）

- **位置**：装配菜单 `EnsureRoomScenery()`，物体挂 `RoomWorld` 下（随房间一起隐藏）
- **内容**：墙 / 地板 / 窗 / 地毯 / 挂画 / 盆栽
- **要点**：`sortingOrder` 用 −100…−50，天然垫在交互物（150xx）后面；让客厅不再是"深蓝底 + 浮空棕块"。

### 5. 对话框放大并贴底

- **文件**：`Assets/Scripts/Dialogue/DialogueBoxUI.cs`
- **要点**：底中黑框 640×120 → **1728×210**（参考分辨率 1920×1080 下接近屏宽），字号 16/22 → 22/28，锚点保持底中。

### 6. 修复 P3：R 重开不清空支线列表

- **文件**：`Assets/Scripts/UI/TaskHints.cs`（实现 `IResettable`，`ResetForNewRun` 清空列表）

### 7. 修复装配非幂等（重要）

- **问题**：特写容器默认 inactive，而装配里用 `GameObject.Find` **找不到 inactive 物体**，
  导致每次重跑菜单都新建一个同名副本（实测 `TidyCloseupRoot` 变成 2 个）。
- **修复**：改用父级作用域的 `EnsureChild(parent, name)`（`Transform.Find` 能找到 inactive 子物体，天然幂等）。

### 8. 占位美术入库

- `room_*`（墙/地板/窗/地毯/挂画/盆栽）、`tidy_furniture_*`、`watercloseup_*`（背景/杯子/水柱/水龙头）、
  `tidycloseup_*`、`water_source` 共 13 张 16×16 纯色 PNG + meta。
