# 策划案 1.1 / 1.2 Demo 验收说明

> 2026-10-16。对应《策划案AI修订版》程序任务核心框架：
> 1.1 游戏流程状态机 GameManager、1.2 一天计时器 DayTimer。

## 一、怎么跑

1. Unity 打开 `Assets/Scenes/TestScene.unity`（**不是 RoomDemo**，玩法骨架都在 TestScene）。
2. 点 Play。
3. 看**屏幕左上角的 [DEMO HUD]**（半透明黑底白字）——流程状态、游戏内时钟、
   剩余秒数、进度条全在上面，不用盯 Console。

如果 HUD 没出现：按 **F1** 切换显示（或在 Inspector 里确认 GameManager 的
`Show Debug Hud` 勾选）。

## 二、HUD 快捷键（Demo 专用）

| 键 | 作用 |
|---|---|
| F1 | 显示/隐藏 HUD |
| T | 快进 60 游戏分钟（= 30 真实秒），不想干等 480 秒时用 |
| R | 结算画面出现后重开一局 |

## 三、逐条验收对照

**1.1 空流程从头跑到尾**

| 步骤 | 预期 |
|---|---|
| 按 Play | HUD 显示「开场独白（3.0s 后进入自由探索）」 |
| 等 3 秒 | 自动切「自由探索」，Console 出 `[流程] 自由探索开始` |
| 按 R（需先到结算）或 Inspector 右键 GameManager → 「重置整局」 | 回到开场独白，计数归零 |

**1.2 到点正确进入结算**

| 步骤 | 预期 |
|---|---|
| 自由探索中 | 时钟从 08:00 起步，每 0.5 真实秒 +1 游戏分钟（480 秒 = 一整天） |
| 倒计时走完 / 按 T 快进 | HUD 切「结算」，进度条归零、停表，Console 出 `[结算] 时间到…` |
| 结算态按 R | 回到开场，剩余秒数恢复 480 |

**吃喝耗时倍率（按策划案保留的机制）**

| 步骤 | 预期 |
|---|---|
| 走到橙色方块（TestSnack）或蓝色方块（TestWater）旁按 E | 对应状态值 +20；HUD 剩余秒数**精确跳减 10**（20 游戏分钟 × 0.5） |
| 拾取后 | 道具消失（一次性） |

> 换算规则全项目只有一处：`DayTimer.SecondsPerGameMinute`（1 游戏分钟 = 0.5 真实秒）。
> 策划案里以后新增耗时（支线打扫、猫打乱等）一律按游戏分钟传给
> `DayTimer.SpendGameMinutes()`，不要自己乘倍率。

## 四、相关文件

| 文件 | 职责 |
|---|---|
| `Assets/Scripts/GameManager.cs` | 1.1 状态机 + 调试 HUD（OnGUI） |
| `Assets/Scripts/DayTimer.cs` | 1.2 480 秒倒计时 + 游戏内时钟 + 倍率换算 |
| `Assets/Scripts/ConsumablePickup.cs` | 吃喝道具（调 `SpendGameMinutes`） |
| `Assets/Scripts/DrawingBoardSetup.cs` | 装配菜单 `GameJam/SetupDrawingBoard (TestScene)`，含测试道具摆放 |
| `Assets/Scenes/Placeholders/` | 测试道具占位图（纯色 PNG），美术资源就位后可删 |

## 五、已知事项

- HUD 是 Demo 占位 UI（IMGUI），正式状态栏/时钟 UI 做好后，删掉
  `GameManager.cs` 里的 `OnGUI` + `HudText` 和三个调试快捷键即可。
- TestScene 里的 TestSnack / TestWater 是验收道具，正式支线玩法做好后可删。
- RoomDemo.unity 是旧场景，已清掉挂着失效脚本的 GameDirector 物体；
  新玩法都在 TestScene 里迭代。
- 本机若同时开多个 Unity 编辑器，MCP 桥接会在实例间漂移，验证时尽量只留一个。
